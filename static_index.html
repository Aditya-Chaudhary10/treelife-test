Treelife AI — Technical Assessment

Two working systems, one FastAPI app. Built by Aditya Chaudhary.

Task 1 · Semantic Business Data Translation Layer

Connect a CRM / project tool (or the built-in messy demo), let it discover how the client really uses the tool, then ask questions in plain English and get answers with reasoning — or an honest explanation of why the data can't answer.

Task 2 · Enterprise Document Workspace

Upload 50 files once. Ask cross-file questions, run SQL over spreadsheets, cross-audit one document against the rest, edit Word/Excel safely and generate new documents — each turn costs a fraction of re-sending everything.
